RAD (Recolhimento pelo Adquirente)

RAD é o mecanismo em que o adquirente da transação — a instituição de pagamento — recolhe e retém a parcela de tributos diretamente na liquidação, repassando ao lojista apenas o valor líquido. O Splithub recebe a guia de DARF gerada nesse fluxo e o comprovante do pagamento realizado, para manter a conciliação completa.

O RAD está relacionado ao split payment previsto na Reforma Tributária: parte do valor da transação pode deixar de transitar pela conta do lojista, sendo recolhida automaticamente pelo adquirente.

Webhook: recepção de guia DARF

Endpoint que a instituição responsável por gerar o DARF no fluxo de RAD deve chamar para entregar a guia ao Splithub assim que ela for emitida.

Nesta versão só é suportada a modalidadePagamento RAD (Recolhimento pelo Adquirente); PRESP (Pagamento pelo Responsável) fica reservado para uma versão futura. Como cada chamada se refere a um único tributo, adicionamos o campo tipoDarf (ibs ou cbs) para identificar qual guia está sendo entregue.
POST /v1/rad/webhooks/darf 
curl -X POST https://api.splithub.com.br/v1/rad/webhooks/darf \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "chaveDfe": "35260714200166000187550010000012341234567890",
    "tipoDarf": "cbs",
    "cdRetorno": "DARF_GERADO",
    "chavePix": "34028316000103",
    "codBarras": "858100000012345678901234567890123456789012",
    "linkDarfPdf": "https://sistema.rfb.gov.br/darf/df_8f3a1c2b.pdf",
    "valorDarfPrincipal": 57.60,
    "valorDarfMulta": 0.00,
    "valorDarfJuros": 0.00,
    "valorDarfTotal": 57.60
  }'

O Splithub confirma o recebimento da guia:

Resposta 200 OK
{
  "id": "darf_9f21ab",
  "chaveDfe": "35260714200166000187550010000012341234567890",
  "tipoDarf": "cbs",
  "status": "recebido"
}

Enviar comprovante de pagamento

Depois de pagar o DARF via PIX, envie o comprovante ao Splithub para conciliar a retenção com o pagamento efetivamente realizado. O formato do objeto pix segue o padrão de webhook Pix recebido do Banco Central (campos endToEndId, txid, chave, valor, horario e infoPagador).

POST /v1/rad/comprovantes 
curl -X POST https://api.splithub.com.br/v1/rad/comprovantes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "darfId": "darf_9f21ab",
    "pix": {
      "endToEndId": "E14200166202607291200a1b2c3d4",
      "txid": "cbs_df_8f3a1c2b",
      "chave": "14200166000187",
      "valor": "57.60",
      "horario": "2026-07-29T12:00:00.000Z",
      "infoPagador": "Pagamento DARF CBS - chave DFe 35260714200166000187550010000012341234567890"
    }
  }'
Resposta 201 Created
{
  "id": "comp_5e21fa",
  "darfId": "darf_9f21ab",
  "status": "confirmado"
}
CampoTipoDescrição
darfIdstringIdentificador do DARF recebido via webhook, ao qual este comprovante se refere
pix.endToEndIdstringIdentificador único da transação Pix
pix.txidstringIdentificador da cobrança Pix associada ao pagamento
pix.chavestringChave Pix usada no pagamento
pix.valorstringValor pago, no mesmo formato do webhook Pix do Banco Central
pix.horariotimestampData e hora da liquidação do Pix
pix.infoPagadorstringInformação livre enviada pelo pagador no Pix
statusstringconfirmado, pendente ou divergente (quando o valor do Pix não bate com o DARF)
