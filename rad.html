RAD (Recolhimento pelo Adquirente)

RAD é o mecanismo em que o adquirente da transação — a instituição de pagamento — recolhe e retém a parcela de tributos diretamente na liquidação, repassando ao lojista apenas o valor líquido. A Splithub configura essas regras de retenção e registra cada retenção aplicada.

O RAD está relacionado ao split payment previsto na Reforma Tributária: parte do valor da transação pode deixar de transitar pela conta do lojista, sendo recolhida automaticamente pelo adquirente.

Configurar uma regra de RAD

Defina o percentual de retenção por arranjo de pagamento e adquirente.

POST /v1/rad/regras 
curl -X POST https://api.splithub.com.br/v1/rad/regras \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "adquirente": "acquirer_x",
    "arranjoPagamento": "pix",
    "percentualRetencao": 0.9
  }'
Resposta 201 Created
{
  "id": "rad_regra_02f1",
  "adquirente": "acquirer_x",
  "arranjoPagamento": "pix",
  "percentualRetencao": 0.9,
  "status": "ativa"
}

Consultar retenções aplicadas

Liste as retenções já aplicadas a uma transação específica.

GET /v1/rad/retencoes?transacaoId= 
curl "https://api.splithub.com.br/v1/rad/retencoes?transacaoId=txn_44a1" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    {
      "id": "rad_ret_9c21",
      "transacaoId": "txn_44a1",
      "valorRetido": 12.35,
      "adquirente": "acquirer_x",
      "status": "recolhido"
    }
  ]
}
CampoTipoDescrição

adquirentestringInstituição de pagamento responsável pela retenção
arranjoPagamentostringpix, boleto, cartao ou transferencia
percentualRetencaonumberPercentual retido pelo adquirente sobre a transação
statusstringativa/inativa (regra) ou recolhido/pendente (retenção)
