Automações

Regras de automação disparam ações — como notificações, webhooks adicionais ou novas regras de separação — automaticamente quando eventos específicos acontecem no sistema.

Cada automação é avaliada de forma assíncrona após o evento que a dispara; consulte o histórico de execuções para confirmar se ela rodou como esperado.

Criar uma automação

Informe o evento que dispara a automação (trigger), condições opcionais e a ação a ser executada.

POST /v1/automacoes 
curl -X POST https://api.splithub.com.br/v1/automacoes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "trigger": "tax_document.completed",   
    "conditions": { "min_total_value": 1000 },
    "action": { "type": "webhook", "url": "https://empresa.com/webhooks/splithub" }
  }'
Resposta 201 Created
{
  "id": "auto_31fd",
  "trigger": "tax_document.completed",
  "status": "active"
}

Mapa de Campos (POST /v1/automacoes):

CampoTipoStatusDescrição
triggerstringOBRIGATÓRIOEvento que dispara a automação (ex.: tax_document.completed, darf.generated)
conditionsobjectOPCIONALCondições adicionais avaliadas antes de executar a ação (ex: min_total_value, status)
actionobjectOBRIGATÓRIOAção executada quando a automação dispara
action.typestringOBRIGATÓRIOTipo de ação (webhook, notification, etc.)
action.urlstringOBRIGATÓRIO*URL de destino (obrigatório quando type = webhook)

Listar automações

Liste as automações configuradas e a data da última execução de cada uma.

GET /v1/automacoes 
curl https://api.splithub.com.br/v1/automacoes \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    {
      "id": "auto_31fd",
      "trigger": "tax_document.completed",
      "status": "active",
      "last_run_at": "2026-07-28T14:32:00Z"
    }
  ]
}
CampoTipoDescrição
idstringIdentificador único da automação
triggerstringEvento que dispara a automação (ex.: tax_document.completed)
conditionsobjectCondições adicionais avaliadas antes de executar a ação
actionobjectAção executada quando a automação dispara
statusstringactive or inactive
