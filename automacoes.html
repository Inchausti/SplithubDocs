Automações

Regras de automação disparam ações — como notificações, webhooks adicionais ou novas regras de separação — automaticamente quando eventos específicos acontecem no sistema.

Cada automação é avaliada de forma assíncrona após o evento que a dispara; consulte o histórico de execuções para confirmar se ela rodou como esperado.

Criar uma automação

Informe o evento que dispara a automação (gatilho), condições opcionais e a ação a ser executada.

POST /v1/automacoes 
curl -X POST https://api.splithub.com.br/v1/automacoes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "gatilho": "documento_fiscal.concluido",
    "condicoes": { "valorTotalMinimo": 1000 },
    "acao": { "tipo": "webhook", "url": "https://empresa.com/webhooks/splithub" }
  }'
Resposta 201 Created
{
  "id": "auto_31fd",
  "gatilho": "documento_fiscal.concluido",
  "status": "ativa"
}

Listar automações

Liste as automações configuradas e a data da última execução de cada uma.

GET /v1/automacoes 
curl https://api.splithub.com.br/v1/automacoes \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    {
      "id": "auto_31fd",
      "gatilho": "documento_fiscal.concluido",
      "status": "ativa",
      "ultimaExecucao": "2026-07-28T14:32:00Z"
    }
  ]
}
CampoTipoDescrição
idstringIdentificador único da automação
gatilhostringEvento que dispara a automação (ex.: documento_fiscal.concluido)
condicoesobjectCondições adicionais avaliadas antes de executar a ação
acaoobjectAção executada quando a automação dispara
statusstringativa ou inativa
