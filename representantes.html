Representantes Fiscais

Gerencie representantes fiscais vinculados a fornecedores no Splithub. Um representante fiscal é fundamental para legitimação de operações fiscais e para cálculos corretos de créditos tributários.

Os dados do representante fiscal são essenciais para validação de documentos fiscais e cálculos de créditos de IBS/CBS. Mantenha sempre os dados do representante atualizados com base nas responsabilidades fiscais vigentes.

Registrar um representante fiscal

Registre um novo representante fiscal vinculado a um fornecedor (CNPJ). O representante é responsável pela legitimação de operações fiscais da empresa.

POST /v1/fornecedores/{cnpj}/representantes 
curl -X POST https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "cpf": "12345678910",
    "name": "John Smith",
    "email": "john@fornecedora.com",
    "phone": "11987654321",
    "rg": "123456789",
    "issuing_body": "SSP"
  }'
Resposta 201 Created
{
  "id": "rep_xyz789",
  "cnpj": "14200166000187",
  "cpf": "12345678910",
  "name": "John Smith",
  "email": "john@fornecedora.com",
  "phone": "11987654321",
  "status": "active",
  "created_at": "2026-08-02T15:30:00.000Z"
}

Mapa de Campos (POST /v1/fornecedores/{cnpj}/representantes):

CampoTipoStatusDescrição
cpfstringOBRIGATÓRIOCPF (11 dígitos)
namestringOBRIGATÓRIONome completo do representante
emailstringOBRIGATÓRIOEmail de contato do representante
phonestringOBRIGATÓRIOTelefone com DDD
rgstringOPCIONALNúmero do RG
issuing_bodystringOPCIONALÓrgão expedidor do RG (SSP, PC, etc)

Listar representantes de um fornecedor

Liste todos os representantes fiscais vinculados a um fornecedor específico (CNPJ).

GET /v1/fornecedores/{cnpj}/representantes 
curl https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{

      "id": "rep_xyz789",
      "cnpj": "14200166000187",
      "cpf": "12345678910",
      "name": "John Smith",

      "phone": "11987654321",
      "status": "active",
      "created_at": "2026-08-02T15:30:00.000Z"
    }

}

Consultar um representante fiscal

Obtenha os dados completos de um representante fiscal específico vinculado a um fornecedor.

GET /v1/fornecedores/{cnpj}/representantes/{id} 
curl https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes/rep_xyz789 \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{

  "cnpj": "14200166000187",
  "cpf": "12345678910",
  "name": "John Smith",
  "email": "john@fornecedora.com",
  "phone": "11987654321",
  "rg": "123456789",
  "issuing_body": "SSP",
  "status": "active",
  "created_at": "2026-08-02T15:30:00.000Z",
  "updated_at": "2026-08-02T15:30:00.000Z"

Atualizar um representante fiscal

Atualize os dados de um representante fiscal. Você pode atualizar qualquer campo que não seja o CPF (identificador imutável).

PATCH /v1/fornecedores/{cnpj}/representantes/{id} 
curl -X PATCH https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes/rep_xyz789 \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "newemail@fornecedora.com.br",
    "phone": "1144445555"
  }'
Resposta 200 OK
{
  "id": "rep_xyz789",
  "cnpj": "14200166000187",
  "email": "newemail@fornecedora.com.br",
  "phone": "1144445555",
  "status": "active",
  "updated_at": "2026-08-02T16:45:00.000Z"
}

Deletar um representante fiscal

Remova um representante fiscal do sistema. Uma vez deletado, o representante não poderá ser utilizado em novas validações de documentos fiscais, mas os históricos permanecerão para auditoria.

DELETE /v1/fornecedores/{cnpj}/representantes/{id} 
curl -X DELETE https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes/rep_xyz789 \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content
