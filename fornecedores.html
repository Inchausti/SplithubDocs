Fornecedores

Gerencie a base de fornecedores da sua empresa no Splithub. Cada fornecedor sincroniza seus dados cadastrais (CNPJ, endereço, contato) e informações do representante fiscal, permitindo rastreabilidade completa e cálculo correto de créditos tributários sobre as compras.

Os dados de CNPJ e do representante fiscal são essenciais para o cálculo correto de créditos de IBS/CBS; mantenha sempre atualizados.

Criar um fornecedor

Registre um novo fornecedor com seus dados cadastrais, informações de contato e dados do representante fiscal responsável.

POST /v1/fornecedores 
curl -X POST https://api.splithub.com.br/v1/fornecedores \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "cnpj": "14200166000187",
    "razaoSocial": "Empresa Fornecedora Ltda",
    "nomeFantasia": "Fornecedora",
    "dataAbertura": "2010-05-15",
    "situacaoCadastral": "ativa",
    "naturezaJuridica": "206",
    "regimeTributario": "lucro_presumido",
    "atividadeEconomica": "4711302",
    "endereco": {
      "logradouro": "Avenida Principal",
      "numero": "1000",
      "complemento": "Sala 200",
      "bairro": "Centro",
      "cidade": "São Paulo",
      "estado": "SP",
      "cep": "01234567"
    },
    "contato": {
      "email": "contato@fornecedora.com.br",
      "telefone": "1133334444"
    },
    "representanteFiscal": {
      "cpf": "12345678910",
      "nome": "João Silva",
      "email": "joao@fornecedora.com.br",
      "telefone": "11987654321",
      "rg": "123456789",
      "orgaoExpedidor": "SSP"
    }
  }'
Resposta 201 Created
{
  "id": "forn_abc123",
  "cnpj": "14200166000187",
  "razaoSocial": "Empresa Fornecedora Ltda",
  "status": "ativo",
  "criadoEm": "2026-07-29T15:30:00.000Z"
}

Listar fornecedores

Liste todos os fornecedores registrados com suporte a paginação e filtros por status ou razão social.

GET /v1/fornecedores 
curl "https://api.splithub.com.br/v1/fornecedores?status=ativo&page=1&limit=20" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    {
      "id": "forn_abc123",
      "cnpj": "14200166000187",
      "razaoSocial": "Empresa Fornecedora Ltda",
      "nomeFantasia": "Fornecedora",

      "criadoEm": "2026-07-29T15:30:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20
}

Atualizar um fornecedor

Atualize os dados de um fornecedor. Você pode atualizar qualquer campo: dados cadastrais, endereço, contato ou informações do representante fiscal.

PATCH /v1/fornecedores/{id} 
curl -X PATCH https://api.splithub.com.br/v1/fornecedores/forn_abc123 \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "nomeFantasia": "Fornecedora Premium",
    "contato": {
      "email": "novo@fornecedora.com.br",
      "telefone": "1144445555"
    }
  }'
Resposta 200 OK
{
  "id": "forn_abc123",
  "cnpj": "14200166000187",
  "nomeFantasia": "Fornecedora Premium",
  "status": "ativo",
  "atualizadoEm": "2026-07-29T16:45:00.000Z"
}

Deletar um fornecedor

Remova um fornecedor do sistema. Uma vez deletado, o fornecedor não poderá ser selecionado em novas operações, mas os históricos permanecerão para auditoria.

DELETE /v1/fornecedores/{id} 
curl -X DELETE https://api.splithub.com.br/v1/fornecedores/forn_abc123 \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content
