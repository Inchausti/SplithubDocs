Fornecedores

Gerencie a base de fornecedores da sua empresa no Splithub. Cada fornecedor sincroniza seus dados cadastrais (CNPJ, endereço, contato), permitindo rastreabilidade completa e cálculo correto de créditos tributários sobre as compras.

Os dados de CNPJ são essenciais para o cálculo correto de créditos de IBS/CBS; mantenha sempre atualizados. CNPJs aceitos em formato alfanumérico conforme especificação da Receita Federal.

Criar um fornecedor

Registre um novo fornecedor com seus dados cadastrais e informações de contato. Para gerenciar representantes fiscais, use o endpoint de Representantes Fiscais.

POST /v1/fornecedores 
curl -X POST https://api.splithub.com.br/v1/fornecedores \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "cnpj": "14200166000187",                
    "legal_name": "Empresa Fornecedora...",  
    "trade_name": "Fornecedora",            
    "founding_date": "2010-05-15",          
    "registration_status": "active",        
    "legal_nature": "206",                  
    "tax_regime": "lucro_presumido",        
    "economic_activity": "4711302",         
    "address": {                            
      "street": "Avenida Principal",         // REQUIRED if address sent
      "number": "1000",                      // REQUIRED if address sent
      "complement": "Sala 200",             
      "neighborhood": "Centro",             // REQUIRED if address sent
      "city": "São Paulo",                  // REQUIRED if address sent
      "state": "SP",                        // REQUIRED if address sent
      "zipcode": "01234567"                 // REQUIRED if address sent
    },
    "contact": {
      "email": "contato@fornecedora.com",   // REQUIRED if contact sent
      "phone": "1133334444"                 // REQUIRED if contact sent
    }
  }'
Resposta 201 Created
{
  "id": "forn_abc123",
  "cnpj": "14200166000187",
  "legal_name": "Empresa Fornecedora Ltda",
  "status": "active",
  "created_at": "2026-07-29T15:30:00.000Z"
}

Listar fornecedores

Liste todos os fornecedores registrados com suporte a paginação e filtros por status ou razão social.

GET /v1/fornecedores 
curl "https://api.splithub.com.br/v1/fornecedores?status=ativo&page=1&limit=20" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    {
      "id": "forn_abc123",
      "cnpj": "14200166000187",
      "legal_name": "Empresa Fornecedora Ltda",
      "trade_name": "Fornecedora",
      "status": "active",
      "created_at": "2026-07-29T15:30:00.000Z"
    }
  ],
  "total": 1,
  "page": 1,
  "limit": 20
}

Atualizar um fornecedor

Atualize os dados de um fornecedor. Você pode atualizar qualquer campo: dados cadastrais, endereço ou contato.

PATCH /v1/fornecedores/{id} 
curl -X PATCH https://api.splithub.com.br/v1/fornecedores/forn_abc123 \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "trade_name": "Fornecedora Premium",
    "contact": {
      "email": "novo@fornecedora.com.br",
      "phone": "1144445555"
    }
  }'
Resposta 200 OK
{
  "id": "forn_abc123",
  "cnpj": "14200166000187",
  "trade_name": "Fornecedora Premium",
  "status": "active",
  "updated_at": "2026-07-29T16:45:00.000Z"
}

Deletar um fornecedor

Remova um fornecedor do sistema. Uma vez deletado, o fornecedor não poderá ser selecionado em novas operações, mas os históricos permanecerão para auditoria.

DELETE /v1/fornecedores/{id} 
curl -X DELETE https://api.splithub.com.br/v1/fornecedores/forn_abc123 \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content
