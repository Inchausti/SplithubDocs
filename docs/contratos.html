Contratos

Gerencie contratos entre CNPJs no Splithub. Registre, atualize e rastreie contratos com referência do seu ERP, dados de ambas as partes, vigência, valor e condições de pagamento.

O campo external_contract_id referencia o contrato no seu ERP; mantenha-o estável para evitar duplicação.

CNPJs são aceitos em formato alfanumérico conforme especificação oficial da Receita Federal (implementação a partir de 27/07/2026).

O campo autorenew define se o contrato será automaticamente renovado na data de término de vigência. Quando true, o contrato é renovável; quando false, o contrato expira sem renovação automática.

Criar um contrato

Registre um novo contrato entre duas empresas, definindo partes, valor, vigência e condições de pagamento.

POST /v1/contratos 
curl -X POST https://api.splithub.com.br/v1/contratos \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "external_contract_id": "CTR-2026-001",     // REQUIRED
    "description": "Contrato de fornecimento",  // REQUIRED
    "buyer_cnpj": "14200166000187",             // REQUIRED
    "supplier_cnpj": "98765432000188",          // REQUIRED
    "start_date": "2026-08-01",                 // REQUIRED
    "end_date": "2027-07-31",                   // REQUIRED
    "total_value": 120000.00,                   // REQUIRED
    "payment_conditions": "30-60-90",           // REQUIRED
    "autorenew": true,                          // REQUIRED
    "rad_eligible": true,                       // REQUIRED
    "status": "active",                         // REQUIRED
    "notes": "Supply contract subject to..."    // OPTIONAL
  }'
Resposta 201 Created
{
  "id": "ctr_5f8a2d",
  "external_contract_id": "CTR-2026-001",
  "status": "active",
  "created_at": "2026-07-29T15:30:00.000Z"
}

Listar contratos

Liste todos os contratos registrados com suporte a paginação e filtros por status, CNPJ ou data.

GET /v1/contratos 
curl "https://api.splithub.com.br/v1/contratos?status=ativo&page=1&limit=20" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK

Consultar um contrato

Obtenha os dados completos de um contrato, incluindo todas as datas, valores e condições.

GET /v1/contratos/{id} 
curl https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "id": "ctr_5f8a2d",

  "description": "Contrato de fornecimento de insumos",

Atualizar um contrato

Atualize qualquer campo de um contrato, incluindo status, datas, valor ou observações.

PATCH /v1/contratos/{id} 
curl -X PATCH https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "end_date": "2027-12-31",
    "payment_conditions": "30-60-90-120",
    "status": "active"
  }'
Resposta 200 OK
{
  "id": "ctr_5f8a2d",
  "external_contract_id": "CTR-2026-001",
  "status": "active",
  "updated_at": "2026-07-29T16:45:00.000Z"
}

Deletar um contrato

Remova um contrato do sistema. Uma vez deletado, o contrato não poderá ser selecionado em novas operações, mas o histórico permanecerá para auditoria.

DELETE /v1/contratos/{id} 
curl -X DELETE https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content
