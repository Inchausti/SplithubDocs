Recursos / Automações

Automações

As automações executam ações em tempo real quando eventos específicos acontecem no Splithub. Inscreva-se via webhook para receber feedback sobre a execução de automações configuradas no portal.

Configure as automações diretamente no portal do Splithub e inscreva-se neste webhook para receber notificações sobre a execução de cada automação. As automações são executadas de forma assíncrona; você receberá feedback imediato sobre o resultado.

Tipos de automações disponíveis

Configure os seguintes tipos de automações no portal Splithub. Cada tipo realiza ações específicas quando eventos fiscais acontecem no sistema.

Integração ITSM

Sincronize automaticamente eventos fiscais com sua plataforma ITSM (Jira, ServiceNow, etc). Crie tickets e registre incidentes baseado em regras fiscais configuradas.

Régua de Cobrança Fornecedor

Dispare automaticamente cobranças e notificações para fornecedores com base em vencimentos, prazos de entrega ou situações fiscais específicas. Automatize fluxos de recuperação de crédito.

Relatórios

Gere e distribua automaticamente relatórios fiscais para stakeholders (CFO, auditoria, compliance). Agende análises periódicas de créditos, débitos e conformidade tributária.

Inscrever-se para receber feedback de automações

Registre uma URL de webhook para receber notificações em tempo real sobre a execução de automações. O portal do Splithub fornece a interface para configurar quais eventos disparam automações.

POST /v1/webhooks/automacoes 
curl -X POST https://api.splithub.com.br/v1/webhooks/automacoes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://empresa.com/webhooks/automacoes",
    "events": ["automation.executed", "automation.failed"]
  }'
Resposta 201 Created
{
  "id": "webhook_abc123",
  "url": "https://empresa.com/webhooks/automacoes",
  "events": ["automation.executed", "automation.failed"],
  "status": "active",
  "created_at": "2026-08-02T15:30:00.000Z"
}

Mapa de Campos (POST /v1/webhooks/automacoes):

CampoTipoStatusDescrição
urlstringOBRIGATÓRIOURL do webhook para receber notificações
eventsarrayOPCIONALTipos de eventos a inscrever (automation.executed, automation.failed). Se vazio, recebe todos

Payload do webhook de automações

Quando uma automação é executada, você receberá uma notificação via POST com as seguintes informações:

Webhook Payload - Automação Executada com Sucesso
{
  "event": "automation.executed",
  "automation_id": "auto_xyz789",
  "trigger": "tax_document.completed",
  "action_type": "webhook",
  "status": "success",
  "execution_time_ms": 245,
  "triggered_at": "2026-08-02T15:45:30.000Z",
  "metadata": {
    "document_id": "doc_12345",
    "total_value": 5000.00
  }
}
Webhook Payload - Automação com Falha
{
  "event": "automation.failed",
  "automation_id": "auto_xyz789",
  "trigger": "tax_document.completed",
  "action_type": "webhook",
  "status": "failed",
  "error_message": "Webhook URL timeout",
  "triggered_at": "2026-08-02T15:50:15.000Z",
  "metadata": {
    "document_id": "doc_12345"
  }
}
CampoTipoDescrição
eventstringautomation.executed ou automation.failed
automation_idstringIdentificador único da automação
triggerstringEvento que disparou a automação
action_typestringTipo de ação executada
statusstringsuccess ou failed
execution_time_msnumberTempo de execução em milissegundos (presente apenas em execuções bem-sucedidas)
error_messagestringDescrição do erro (presente apenas em falhas)
triggered_attimestampData e hora da execução da automação
metadataobjectDados contextuais relacionados ao evento que disparou a automação
