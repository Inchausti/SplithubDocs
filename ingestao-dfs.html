Ingestão DFs

A Splithub permite enviar (ingerir) Documentos Fiscais — NF-e, NFC-e e CT-e — para que os tributos de cada documento sejam identificados e processados automaticamente pelas regras de separação.

Aceitamos o XML assinado do documento fiscal ou um JSON estruturado equivalente. O processamento é assíncrono; use o endpoint de consulta para acompanhar o status.

Enviar um documento fiscal

Envie o XML do documento fiscal em base64 ou os campos já estruturados. A API retorna um identificador para acompanhar o processamento.

POST /v1/documentos-fiscais 
curl -X POST https://api.splithub.com.br/v1/documentos-fiscais \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "tipo": "nfe",
    "chaveAcesso": "35260714200166000187550010000012341234567890",
    "xmlBase64": "PD94bWwgdmVyc2lvbj0iMS4wIj8+..."
  }'

A resposta confirma o recebimento e o status inicial do processamento:

Resposta 202 Accepted
{
  "id": "df_8f3a1c2b",
  "status": "processando",
  "tipo": "nfe",
  "chaveAcesso": "35260714200166000187550010000012341234567890"
}

Consultar status da ingestão

Use o id retornado para consultar o andamento do processamento e os tributos identificados no documento.

GET /v1/documentos-fiscais/{id} 
curl https://api.splithub.com.br/v1/documentos-fiscais/df_8f3a1c2b \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "id": "df_8f3a1c2b",
  "status": "concluido",
  "valorTotal": 15420.00,
  "tributosIdentificados": {
    "cbs": 138.78,
    "ibs": 15.42
  }
}
CampoTipoDescrição
idstringIdentificador único do documento fiscal ingerido
tipostringTipo do documento: nfe, nfce ou cte
statusstringprocessando, concluido ou erro
valorTotalnumberValor total do documento fiscal
tributosIdentificadosobjectValores de CBS e IBS identificados no documento
