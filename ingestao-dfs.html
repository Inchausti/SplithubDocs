Ingestão DFs

O Splithub permite enviar (ingerir) Documentos Fiscais para que os tributos de cada documento sejam identificados e processados automaticamente pelas regras de separação. Com a Reforma Tributária, o Fisco passa a trabalhar com 14 tipos de DFs (Documentos Fiscais Eletrônicos), cada um cobrindo uma categoria diferente de operação.

Tipos de documentos fiscais (DFs)

Estes são os 14 tipos de DF-e previstos, com o modelo oficial e o tipo de operação que cada um documenta. Informe o tipo correto no campo type ao criar um documento.

SiglaNomeModeloCobre
nfeNota Fiscal Eletrônica (NF-e)55Circulação de mercadorias entre empresas
nfceNota Fiscal de Consumidor Eletrônica (NFC-e)65Vendas ao consumidor final, presenciais ou por entrega
cteConhecimento de Transporte Eletrônico (CT-e)57Prestação de serviço de transporte de cargas
cte-osCT-e para Outros Serviços (CT-e OS)67Outros serviços vinculados ao transporte (excesso de bagagem, multimodal, internacional de carga)
bpeBilhete de Passagem Eletrônico (BP-e)63Transporte de passageiros intermunicipal, interestadual e internacional
mdfeManifesto de Documentos Fiscais Eletrônicos (MDF-e)58Reúne os documentos fiscais vinculados a uma carga transportada

Aceitamos o XML assinado do documento fiscal ou um JSON estruturado equivalente aos grupos da NF-e 4.0 atualizados pela Nota Técnica 2025.002 — o Grupo UB (IBS/CBS por item, dentro de items[].tax) e o Grupo W03 (totais de IBS/CBS da nota). Sem esses grupos preenchidos, a partir de 03/08/2026 a nota é rejeitada pela SEFAZ. O processamento na Splithub é assíncrono; use o endpoint de consulta para acompanhar o status.

Criar um documento fiscal

Envie o XML do documento em base64 ou os campos já estruturados, seguindo os grupos do layout da NF-e 4.0: identification (identificação), emission (emitente), destination (destinatário), items (equivalente ao grupo det, já com o Grupo UB de IBS/CBS por item) e total (com o Grupo W03 de totais de IBS/CBS). A API retorna um identificador para acompanhar o processamento.

POST /v1/documentos-fiscais 
curl -X POST https://api.splithub.com.br/v1/documentos-fiscais \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "nfe",
    "model": "55",
    "access_key": "35260714200166000187550010000012341234567890",
    "identification": {
      "number": "123456",
      "series": "1",
      "emission_date": "2026-07-29T10:00:00-03:00"
    },
    "emission": {
      "cnpj": "14200166000187",
      "legal_name": "Fornecedor Exemplo LTDA",
      "state": "SP"
    },
    "destination": {
      "cnpj_cpf": "98765432000188",
      "name": "Cliente Exemplo LTDA",
      "state": "RJ"
    },
    "items": [
      {
        "code": "SKU-1029",
        "description": "Notebook 15pol 16GB",
        "ncm": "84713012",
        "cfop": "5102",
        "quantity": 2,
        "unit_price": 3200.00,
        "total_value": 6400.00,
        "tax": {
          "ibs_cbs": {
            "CST": "000",
            "cClassTrib": "000001",
            "vBC": 6400.00,
            "gIBSUF": { "pIBSUF": 0.05, "vIBSUF": 3.20 },
            "gIBSMun": { "pIBSMun": 0.05, "vIBSMun": 3.20 },
            "gCBS": { "pCBS": 0.9, "vCBS": 57.60 }
          }
        }
      }
    ],
    "total": {
      "products_value": 6400.00,
      "total_note_value": 6400.00,
      "ibs_cbs_total": {
        "vBC": 6400.00,
        "vTotIBS": 6.40,
        "vTotCBS": 57.60
      }
    }
  }'
Durante 2026, vTotIBS e vTotCBS não compõem o valorTotalNota — eles são informados à parte no Grupo W03, refletindo a fase de testes com cobrança simbólica (0,9% CBS + 0,1% IBS, dividido entre gIBSUF e gIBSMun).

A resposta confirma o recebimento e o status inicial do processamento:

Resposta 202 Accepted
{
  "id": "df_8f3a1c2b",
  "status": "processing",
  "type": "nfe",
  "model": "55",
  "access_key": "35260714200166000187550010000012341234567890"
}

Consultar um documento fiscal

Use o id retornado para consultar o andamento do processamento e os tributos identificados no documento.

GET /v1/documentos-fiscais/{id} 
curl https://api.splithub.com.br/v1/documentos-fiscais/df_8f3a1c2b \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "id": "df_8f3a1c2b",
  "status": "completed",
  "type": "nfe",
  "emission": { "cnpj": "14200166000187", "legal_name": "Fornecedor Exemplo LTDA" },
  "destination": { "cnpj_cpf": "98765432000188", "name": "Cliente Exemplo LTDA" },
  "total_value": 6400.00,
  "ibs_cbs_total": {
    "vBC": 6400.00,
    "vTotIBS": 6.40,
    "vTotCBS": 57.60
  }
}

Listar documentos fiscais

Liste os documentos ingeridos, com filtros opcionais por type e status.

GET /v1/documentos-fiscais 
curl "https://api.splithub.com.br/v1/documentos-fiscais?tipo=nfe&status=concluido" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "data": [
    { "id": "df_8f3a1c2b", "type": "nfe", "status": "completed", "total_value": 6553.60 }
  ],
  "page": 1,
  "perPage": 20,
  "total": 1
}

Atualizar um documento fiscal

Corrija campos de um documento antes de ele ser concluído — por exemplo, dados do destinatário ou itens registrados com erro.

Só é possível atualizar um documento com status pending ou error. Documentos com status completed são imutáveis, refletindo a legislação fiscal.
PATCH /v1/documentos-fiscais/{id} 
curl -X PATCH https://api.splithub.com.br/v1/documentos-fiscais/df_8f3a1c2b \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "destination": {
      "cnpj_cpf": "98765432000188",
      "name": "Cliente Exemplo LTDA - Matriz"
    }
  }'
Resposta 200 OK
{
  "id": "df_8f3a1c2b",
  "status": "pending",
  "destination": { "cnpj_cpf": "98765432000188", "name": "Cliente Exemplo LTDA - Matriz" }
}

Remover um documento fiscal

Remove o registro de ingestão da Splithub — não é o mesmo que cancelar o documento junto ao Fisco, que continua sendo feito no seu sistema emissor.

DELETE /v1/documentos-fiscais/{id} 
curl -X DELETE https://api.splithub.com.br/v1/documentos-fiscais/df_8f3a1c2b \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content
