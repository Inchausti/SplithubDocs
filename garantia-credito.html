Garantia de crédito

O Splithub permite vincular parte dos recebíveis futuros de uma empresa como garantia de operações de crédito ou contratos, bloqueando o valor correspondente até a liberação ou execução da garantia.

Uma garantia bloqueada reduz o saldo disponível para saque nos relatórios de posição, mas não afeta a separação de tributos das transações.

Criar uma garantia

Informe o tipo, o valor e a vigência da garantia. Se ela estiver associada a um contrato sincronizado, informe também o contratoId.

POST /v1/garantias 
curl -X POST https://api.splithub.com.br/v1/garantias \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "tipo": "recebiveis",
    "valor": 50000.00,
    "vigenciaInicio": "2026-08-01",
    "vigenciaFim": "2027-08-01",
    "contratoId": "contrato_771a"
  }'
Resposta 201 Created
{
  "id": "gar_5b12",
  "tipo": "recebiveis",
  "valor": 50000.00,
  "status": "ativa"
}

Consultar garantias ativas

Consulte o saldo executado e o status atual de uma garantia pelo seu identificador.

GET /v1/garantias/{id} 
curl https://api.splithub.com.br/v1/garantias/gar_5b12 \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "id": "gar_5b12",
  "tipo": "recebiveis",
  "valor": 50000.00,
  "valorExecutado": 0,
  "status": "ativa",
  "vigenciaFim": "2027-08-01"
}
CampoTipoDescrição
idstringIdentificador único da garantia
tipostringrecebiveis ou contrato
valornumberValor total bloqueado como garantia
statusstringativa, liberada ou executada
vigenciaFimdateData de encerramento da garantia
