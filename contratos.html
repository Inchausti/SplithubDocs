Contratos

Gerencie contratos entre CNPJs no Splithub. Registre, atualize e rastreie contratos com referência do seu ERP, dados de ambas as partes, vigência, valor e condições de pagamento.

O campo external_contract_id referencia o contrato no seu ERP; mantenha-o estável para evitar duplicação.

CNPJs são aceitos em formato alfanumérico conforme especificação oficial da Receita Federal (implementação a partir de 27/07/2026).

O campo autorenew define se o contrato será automaticamente renovado na data de término de vigência. Quando true, o contrato é renovável; quando false, o contrato expira sem renovação automática.

Criar um contrato

Registre um novo contrato entre duas empresas, definindo partes, valor, vigência e condições de pagamento.

POST /v1/contratos 
curl -X POST https://api.splithub.com.br/v1/contratos \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "external_contract_id": "CTR-2026-001",
    "description": "Contrato de fornecimento",
    "buyer_cnpj": "14200166000187",
    "supplier_cnpj": "98765432000188",
    "start_date": "2026-08-01",
    "end_date": "2027-07-31",
    "total_value": 120000.00,
    "payment_conditions": "30-60-90",
    "autorenew": true,
    "rad_eligible": true,
    "status": "active",
    "notes": "Supply contract subject to Tax Reform - IBS/CBS"
  }'
Resposta 201 Created
{
  "id": "ctr_5f8a2d",
  "external_contract_id": "CTR-2026-001",
  "status": "active",
  "created_at": "2026-07-29T15:30:00.000Z"
}

Mapa de Campos (POST /v1/contratos):

CampoTipoStatusDescrição
external_contract_idstringOBRIGATÓRIOReferência do contrato no seu ERP (manter estável para evitar duplicação)
descriptionstringOBRIGATÓRIODescrição/objeto do contrato
buyer_cnpjstringOBRIGATÓRIOCNPJ da empresa contratante (alfanumérico)
supplier_cnpjstringOBRIGATÓRIOCNPJ da empresa contratada (alfanumérico)
start_datedateOBRIGATÓRIOData de início da vigência (YYYY-MM-DD)
end_datedateOBRIGATÓRIOData de término/vigência (YYYY-MM-DD)
total_valuenumberOBRIGATÓRIOValor total do contrato
payment_conditionsstringOBRIGATÓRIOCondições de pagamento (ex: 30-60-90)
autorenewbooleanOBRIGATÓRIOtrue ou false — define se o contrato é autorenovável
rad_eligiblebooleanOBRIGATÓRIOtrue ou false — define se é sujeito a RAD
statusstringOBRIGATÓRIOactive, closed, suspended ou cancelled
notesstringOPCIONALObservações e anotações sobre o contrato

Listar contratos

Liste todos os contratos registrados com suporte a paginação e filtros por status, CNPJ ou data.

GET /v1/contratos

Atualizar um contrato

Atualize qualquer campo de um contrato, incluindo status, datas, valor ou observações.

PATCH /v1/contratos/{id} 
curl -X PATCH https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "end_date": "2027-12-31",
    "payment_conditions": "30-60-90-120",
    "status": "active"
  }'
Resposta 200 OK
{
  "id": "ctr_5f8a2d",
  "external_contract_id": "CTR-2026-001",
  "status": "active",
  "updated_at": "2026-07-29T16:45:00.000Z"
}

Deletar um contrato

Remova um contrato do sistema. Uma vez deletado, o contrato não poderá ser selecionado em novas operações, mas o histórico permanecerá para auditoria.

DELETE /v1/contratos/{id} 
curl -X DELETE https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content

Representantes Fiscais

    

      Gerencie representantes fiscais vinculados a contratos. Um representante fiscal
      é fundamental para legitimação de operações fiscais e para cálculos corretos de créditos tributários.
    


    

      
      

        
Os dados do representante fiscal são essenciais para validação de documentos fiscais e cálculos de créditos de IBS/CBS. Mantenha sempre os dados do representante atualizados com base nas responsabilidades fiscais vigentes.

      

    


    
Registrar um representante fiscal

    

      Registre um novo representante fiscal vinculado a um contrato (CNPJ). O representante
      é responsável pela legitimação de operações fiscais da empresa.
    


    

      

        POST /v1/fornecedores/{cnpj}/representantes
        
      

      
curl -X POST https://api.splithub.com.br/v1/fornecedores/14200166000187/representantes \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "cpf": "12345678910",
    "name": "John Smith",
    "email": "john@fornecedora.com",
    "phone": "11987654321",
    "rg": "123456789",
    "issuing_body": "SSP"
  }'

    


    

      
Resposta 201 Created

      
{
  "id": "rep_xyz789",
  "cnpj": "14200166000187",
  "cpf": "12345678910",
  "name": "John Smith",
  "email": "john@fornecedora.com",
  "phone": "11987654321",
  "status": "active",
  "created_at": "2026-08-02T15:30:00.000Z"
}

    


    
Mapa de Campos (POST /v1/fornecedores/{cnpj}/representantes):

    

      
CampoTipoStatusDescrição

      
cpfstringOBRIGATÓRIOCPF (11 dígitos)

      
namestringOBRIGATÓRIONome completo do representante

      
emailstringOBRIGATÓRIOEmail de contato do representante

      
phonestringOBRIGATÓRIOTelefone com DDD

      
rgstringOPCIONALNúmero do RG

      
issuing_bodystringOPCIONALÓrgão expedidor do RG (SSP, PC, etc)
