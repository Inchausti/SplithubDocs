Contratos

A sincronização de contratos vincula os contratos do seu sistema ao Splithub, associando obrigações fiscais e financeiras — como garantias e regras de RAD — a cada contrato.

Mantenha o contratoExternoId estável entre sincronizações: é ele que o Splithub usa para atualizar (e não duplicar) um contrato já existente.

Sincronizar um contrato

Envie os dados do contrato do seu sistema de origem. Se já existir um contrato com o mesmo contratoExternoId, ele é atualizado em vez de duplicado.

POST /v1/contratos/sync 
curl -X POST https://api.splithub.com.br/v1/contratos/sync \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "contratoExternoId": "contrato_771a",
    "partes": ["empresa_123", "cliente_456"],
    "valor": 120000.00,
    "vigenciaFim": "2027-08-01"
  }'
Resposta 200 OK
{
  "id": "ctr_9a44",
  "contratoExternoId": "contrato_771a",
  "statusSync": "sincronizado"
}

Consultar um contrato sincronizado

Consulte o status de sincronização e a data da última atualização de um contrato.

GET /v1/contratos/{id} 
curl https://api.splithub.com.br/v1/contratos/ctr_9a44 \
  -H "Authorization: Bearer {token}"
Resposta 200 OK
{
  "id": "ctr_9a44",
  "contratoExternoId": "contrato_771a",
  "statusSync": "sincronizado",
  "ultimaSincronizacao": "2026-07-29T10:00:00Z"
}
