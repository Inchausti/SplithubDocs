Contratos

Gerencie contratos entre CNPJs no Splithub. Registre, atualize e rastreie contratos com referência do seu ERP, dados de ambas as partes, vigência, valor e condições de pagamento.

O campo contratoExternoId referencia o contrato no seu ERP; mantenha-o estável para evitar duplicação.

Criar um contrato

Registre um novo contrato entre duas empresas, definindo partes, valor, vigência e condições de pagamento.

POST /v1/contratos 
curl -X POST https://api.splithub.com.br/v1/contratos \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "contratoExternoId": "CTR-2026-001",
    "descricao": "Contrato de fornecimento de insumos",
    "cnpjContratante": "14200166000187",
    "cnpjContratado": "98765432000188",
    "dataInicio": "2026-08-01",
    "dataFim": "2027-07-31",
    "valorTotal": 120000.00,
    "condicaoPagamento": "30-60-90",
    "optanteRAD": true,
    "status": "ativo",
    "observacoes": "Contrato sujeito à Reforma Tributária - IBS/CBS"
  }'
Resposta 201 Created
{
  "id": "ctr_5f8a2d",
  "contratoExternoId": "CTR-2026-001",
  "status": "ativo",
  "criadoEm": "2026-07-29T15:30:00.000Z"
}

Listar contratos

Liste todos os contratos registrados com suporte a paginação e filtros por status, CNPJ ou data.

GET /v1/contratos 
curl "https://api.splithub.com.br/v1/contratos?status=ativo&page=1&limit=20" \
  -H "Authorization: Bearer {token}"
Resposta 200 OK

Consultar um contrato

Obtenha os dados completos de um contrato, incluindo todas as datas, valores e condições.

GET /v1/contratos/{id} 
curl https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}"

Atualizar um contrato

Atualize qualquer campo de um contrato, incluindo status, datas, valor ou observações.

PATCH /v1/contratos/{id} 
curl -X PATCH https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "dataFim": "2027-12-31",
    "condicaoPagamento": "30-60-90-120",
    "status": "ativo"
  }'
Resposta 200 OK
{
  "id": "ctr_5f8a2d",
  "contratoExternoId": "CTR-2026-001",
  "status": "ativo",
  "atualizadoEm": "2026-07-29T16:45:00.000Z"
}

Deletar um contrato

Remova um contrato do sistema. Uma vez deletado, o contrato não poderá ser selecionado em novas operações, mas o histórico permanecerá para auditoria.

DELETE /v1/contratos/{id} 
curl -X DELETE https://api.splithub.com.br/v1/contratos/ctr_5f8a2d \
  -H "Authorization: Bearer {token}"
Resposta 204 No Content

    


    

      
CampoTipoDescrição

      
idstringIdentificador único do contrato no Splithub

      
contratoExternoIdstringReferência do contrato no seu ERP

      
descricaostringDescrição/objeto do contrato

      
cnpjContratantestringCNPJ da empresa contratante (14 dígitos)

      
cnpjContratadostringCNPJ da empresa contratada (14 dígitos)

      
dataIniciodateData de início da vigência (YYYY-MM-DD)

      
dataFimdateData de término/vigência (YYYY-MM-DD)

      
valorTotalnumberValor total do contrato

      
condicaoPagamentostringCondições de pagamento (ex: 30-60-90)

      
optanteRADbooleantrue ou false — define se o contrato é sujeito a RAD (Recolhimento pelo Adquirente)

      
statusstringativo, encerrado, suspenso ou cancelado

      
observacoesstringObservações e anotações sobre o contrato

      
criadoEmtimestampData e hora da criação

      
atualizadoEmtimestampData e hora da última atualização
